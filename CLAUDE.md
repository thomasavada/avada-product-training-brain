1. This is a public repository. Never commit credentials, private customer data, raw internal transcripts, private Slack exports or proprietary source photographs/OCR.
2. Knowledge claims must carry evidence status. Learner and vendor claims are not audited facts.
3. `plugins/avada-product-training/.claude-plugin/plugin.json`, `.codex-plugin/plugin.json` and both marketplace entries must share the same version.
4. Any skill or knowledge change requires a plugin version bump before release.
5. Keep skills thin; doctrine belongs in `knowledge/`.
6. Do not copy raw Interloka source images/OCR into this public repo. Include only Thomas/Avada synthesis and public video links.
7. Preserve attribution for Chase Chappell and Pocock teaching-pattern inspirations.
8. Validate both plugin and marketplace, run link/source checks, and behavior-test positive plus negative triggers before publishing.
