# Learning habit system

## Goal

Turn ecommerce/business learning into repeated observation, application and correction. Content consumption is input; the habit is complete only when it produces an artifact or changed decision.

## Minimum viable cadence

Default when the learner has not chosen a cadence:

- **3 × 30 minutes/week** — observation and short practice;
- **1 × 60 minutes/week** — one brand/app teardown;
- **1 × 30 minutes/week** — review, correction and next plan.

Reduce scope before skipping the week.

## Habit loop

```text
Cue
→ retrieve from memory
→ inspect one real source
→ create one small artifact
→ get challenge/feedback
→ revise
→ log the lesson
```

## Weekly pattern

### Session A — Learn one thing

- Pick one concept from the mission.
- Read/watch one primary source.
- Write three recalled points without reopening the source.
- Produce a glossary card, equation or mechanism map.

### Session B — Apply to reality

- Choose one live brand, merchant or app.
- Capture source URLs/screenshots.
- Apply the concept.
- Label fact, inference, assumption and unknown.

### Session C — Challenge

- Ask the brain or a peer to attack the weakest assumption.
- Recheck the primary source.
- Revise the artifact.
- Record what changed.

### Weekly clinic

Create one of:

- brand diagnosis;
- app value contract;
- offer economics model;
- competitor contrast;
- stage/KPI diagnosis.

## Workspace contract

- `MISSION.md` — capability and real work context.
- `LEARNING-HABIT.md` — cadence, cue, minimum action and review day.
- `RESOURCES.md` — short queue with active prompts, max five items.
- `practice-log/YYYY-MM-DD.md` — source, artifact, challenge, correction.
- `learning-records/NNNN-<lesson>.md` — only demonstrated durable learning.
- `weekly-reviews/YYYY-Www.md` — evidence of practice and next bottleneck.

## Queue limits

- Maximum five unwatched resources.
- Maximum one active course/topic per mission.
- A new source enters only when it has a planned artifact.
- Archive sources that do not serve the current mission.

## 30-day starter

### Week 1 — Foundation and baseline

- Diagnostic quiz: terminology, grain and arithmetic.
- One worked example.
- Set mission and cadence.

### Week 2 — Brand observation

- One live storefront teardown.
- One competitor contrast.
- One corrected stage diagnosis.

### Week 3 — App/product economics

- One app value deep dive.
- Downside/base/upside model.
- Pricing and proof plan.

### Week 4 — Teach back

- Explain one mechanism without notes.
- Apply it to a changed case.
- Publish or present one revised artifact.
- Choose next month's bottleneck.

## Habit scorecard

Track behavior and artifacts, not minutes watched:

| Signal | Weekly target |
|---|---:|
| Retrieval attempts | 3 |
| Live sources inspected | 3 |
| Artifacts created | 2 |
| Assumptions challenged | 2 |
| Artifacts revised | 1 |
| Learning record earned | 0–1 |

A learning record is earned only when the learner can transfer the idea to a changed case.

## Failure recovery

If the habit stops:

1. Cut the next action to 10 minutes.
2. Reuse the current source; do not hunt for a better course.
3. Produce a tiny artifact.
4. Schedule the next cue before ending.
5. Review whether the mission is still tied to real work.

Do not solve inconsistency by adding more resources.
