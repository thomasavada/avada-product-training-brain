# Blue Ocean Strategy & Value Innovation

**Source range:** primarily `IMG_7154`–`IMG_7157`, with applications elsewhere.

## [SOURCE] Break the status quo

The course challenges category assumptions such as:

- travel must mean hotels;
- wine must be old/ritualized;
- circus must include animals and dangerous stunts;
- CRM is only for large companies.

The purpose is not novelty by itself. It is to identify inherited category factors that can be reconfigured.

## [SOURCE] Strategy Canvas and Four Actions

`IMG_7155` uses the Yellow Tail case and the four actions:

- **Reduce** certain traditional factors;
- **Raise** factors valuable to a broader audience;
- **Create** a new wine experience/category expression;
- **Eliminate** ritual and complexity that do not support the chosen buyer value.

## [SOURCE] Value Innovation

`IMG_7155`–`IMG_7156` define value innovation as simultaneously pursuing:

- differentiation in product/service value;
- lower or restructured cost;
- increased value for customers and the enterprise.

The course explicitly contrasts:

```text
Traditional competition:
cost rises roughly with value

Value innovation:
value rises materially more than cost
```

Cost reduction comes from eliminating/reducing less-important industry attributes. New customer value comes from raising/creating important attributes.

## [SOURCE] Red Ocean vs Blue Ocean

Red Ocean:

- compete in existing space;
- beat competitors;
- exploit existing demand;
- accept the value/cost trade-off;
- align activities with either differentiation or low cost.

Blue Ocean:

- create new market space;
- make competition less relevant;
- create and capture demand;
- break the value/cost trade-off;
- align the activity system with differentiation **and** low cost.

## Global case set for teaching

Use globally recognizable examples instead of the local source case:

- **Yellow Tail:** canonical Strategy Canvas/Four Actions case; simplify wine choice and create a fun, accessible social drink.
- **Cirque du Soleil:** remove costly circus conventions and create theatre-like storytelling/value.
- **IKEA:** align flat-pack design, self-service, customer assembly, supply chain, and accessible design.
- **Ryanair/Southwest:** show a sharply different airline value curve and activity system. Use Ryanair with a caveat: low cost alone is not automatically a Blue Ocean.

Detailed walkthroughs: `case-studies/global/blue-ocean-global-cases.md`.

## [SOURCE] Important boundary

`IMG_7156` states Blue Ocean is not automatically creative destruction; new market creation can coexist with existing products.

## [SYNTHESIS] Evaluation checklist

- What category assumptions are inherited rather than necessary?
- Which factor reductions fund the new value?
- Is buyer utility meaningfully higher?
- Does target cost support the promised price?
- Are activities aligned, or is this merely extra features?
- What adoption barrier prevents the new curve from working?
