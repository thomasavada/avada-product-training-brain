# Interactive training and case-clinic method

## Diagnosis

Passive failure signs:

- attendance without preparation;
- few notes/questions;
- sitting back and avoiding interaction;
- repeating vocabulary without applying it;
- AI-generated answers with no personal judgment;
- more theory added before prior capability is tested.

Do not fix passivity by adding more slides.

## Learning contract

Learners own preparation, punctuality, laptop/materials, questions and participation.

Allowed:

- wrong estimates;
- “I do not know”;
- ranges;
- changing conclusion after evidence.

Not allowed:

- no preparation;
- hiding uncertainty with jargon;
- numbers without assumptions;
- AI doing the observation/judgment;
- claims without evidence.

## Case grammar

For each real source:

```text
inspect/watch
→ predict/map
→ individual or pair response
→ group share
→ reveal/debrief
→ revise artifact
```

Never put the complete answer next to the source before learners commit a hypothesis.

## Case-clinic cadence

Per group:

1. 5 min — diagnosis.
2. 5 min — peer challenge.
3. 5 min — instructor probes evidence/mechanism/economics.
4. 5 min — group revises conclusion.

The instructor asks:

- Evidence đâu?
- Fact hay inference?
- Denominator/grain/window là gì?
- Mechanism nào làm behavior đổi?
- Value/contribution bao nhiêu?
- Data nào sẽ prove/disprove?

## Kahoot role

Use Kahoot as diagnostic/retrieval:

- terminology (OEM, AOV, COGS, CVR, CAC, CLV);
- denominator/grain;
- quick arithmetic;
- identify wrong inference;
- select metric for one job.

Do not use Kahoot as proof of product judgment.

Suggested sequence:

```text
8–12 question diagnostic
→ 10–15 min targeted refresh
→ real case
→ short misconception check
```

## Spaced-practice design

Business sense is not completed in four to six sessions.

```text
foundation
→ practice
→ reconnect
→ new concept
→ contrasting case
→ correction
→ repeat
```

Each external video/source should include:

- what to watch;
- what to note;
- which brand to apply it to;
- which artifact to submit.

## Scaffold ladder

1. Completed worked example.
2. Partially completed worksheet.
3. Blank worksheet.
4. Open-ended case.

A worksheet is a scaffold, not a recipe. Remove it gradually.

## Multiple-case contrast

One deep instructor case helps novices learn process. Several contrasting cases prevent overfitting.

Use the same framework across different:

- categories;
- stages;
- channel mixes;
- economics;
- answers.

## Progress measurement

Track:

- quiz misconception baseline;
- evidence quality;
- stage reasoning;
- economics;
- personal judgment;
- falsification quality;
- peer challenge;
- revision after feedback;
- storytelling coherence.

Self-reported confidence is secondary to artifact quality.
