# Learning Habit Builder

## Read first

- `knowledge/learning-habit-system.md`
- `knowledge/sources/channel-guide.md`
- `knowledge/sources/learning-resources.md`
- `knowledge/principles/artifact-and-correction.md`
- `knowledge/principles/no-ai-outsourcing-judgment.md`

## Procedure

### 1. Set the mission

Capture:

- capability to improve;
- real work where it will be used;
- current baseline;
- evidence that improvement happened.

If the user has not specified time, default to three 30-minute practices plus one weekly clinic. Do not block setup with a long interview.

### 2. Create the workspace

Write:

- `MISSION.md`;
- `LEARNING-HABIT.md`;
- `RESOURCES.md`;
- `practice-log/`;
- `weekly-reviews/`;
- `learning-records/`.

Keep the resource queue at five or fewer.

### 3. Choose sources by job

Use `channel-guide.md` and `learning-resources.md`. Every source must have:

```text
why this source
what to notice
which case to apply it to
which artifact to produce
```

Do not create a passive playlist.

### 4. Schedule the loop

```text
retrieve
→ inspect source
→ apply to live case
→ create artifact
→ challenge
→ revise
→ log
```

Tie the cue to the learner's actual work calendar when possible.

### 5. Run weekly review

Review:

- artifacts, not watch time;
- strongest observation;
- weakest assumption;
- correction made;
- transfer to a changed case;
- next bottleneck.

Do not reward attendance or completed videos as mastery.

### 6. Recover quickly

When the learner misses a week, shrink the next task to ten minutes and reuse the current source. Never respond by adding a new course or a bigger backlog.

## Output

- Mission.
- Cadence and cue.
- 30-day sequence.
- Resource queue with active prompts.
- Artifact plan.
- Weekly scorecard.
- Recovery rule.

## Completion

The habit is established when the learner repeatedly creates, receives challenge on and revises work artifacts without needing the trainer to assign every source.
